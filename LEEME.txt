ROMEC WEB PRO v4.2 — PAQUETE ESTÁTICO PARA NETLIFY (MODO CLARO)

ESTE PROYECTO NO NECESITA NODE.JS, NPM, BASE DE DATOS, BACKEND NI PANEL ADMINISTRATIVO.

PUBLICACIÓN DIRECTA:
1. Entra a https://app.netlify.com/drop
2. Arrastra el ZIP ROMEC_NETLIFY_DEPLOY.zip tal cual (index.html está en la raíz), o descomprímelo y arrastra la carpeta.
3. Netlify te dará una URL *.netlify.app. Puedes cambiar el nombre en Site configuration > Change site name.

PUBLICACIÓN CON GITHUB:
- Build command: echo 'ROMEC static site ready'
- Publish directory: .
- Sin variables de entorno.
